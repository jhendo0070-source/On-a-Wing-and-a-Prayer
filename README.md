# This program calculates and displays the deflction along a wing of selected materials at variable velocities and altitudes
# Based on selections of materials and velocities the program will display a plot, visualizing the deflection along the wing of selected aircrafts.
# The program can easily be expanded upon with new aircraft types or materials with just a little bit of information about the material and/or aircraft.
